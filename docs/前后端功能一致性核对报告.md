# GeoDataManage 前后端功能一致性核对报告

> 核对范围：`geodata-web`（19 个业务 Controller / ~200 端点） × `geodata-web-ui`（14 页面 / 9 个 API 模块）
> 核对方式：逐端点比对「路径 + HTTP 方法 + 参数绑定方式 + 参数名大小写 + 返回体形态」，再核对页面是否实际调用。
> 结论一句话：**API 声明层（api/modules/*.ts）与后端契约高度吻合，未发现路径/方法级致命错配；不一致集中在「页面覆盖缺口」与「少量参数顺序/调用方式」上。**
>
> **修复状态（2026-10-10 更新）**：本报告中的 P0 全部修复、P1 全部修复、P2 大部分落地。详见文末「七、修复落地清单」。

## 一、致命问题（会导致功能失效）

| # | 位置 | 现象 | 证据 | 修复建议 |
|---|---|---|---|---|
| **P0-1** | `api/modules/style.ts` → `symbolApi.getAllListPage` | 参数名顺序写反。前端传 `{PageIndex, PageSize}`，后端要求 `PageSize` 在前、`PageIndex` 在后且**均为必填**。axios 按对象键序拼接，实际发出的 query 顺序为 `PageIndex&PageSize` —— Spring 按名绑定，顺序不影响绑定正确性，**但前端默认值方向易误用**（默认 `PageIndex=1,PageSize=10` 恰好正确，故当前不炸，属隐患）。 | 后端 `SymbolController.getAllListPage(@RequestParam("PageIndex") int pageIndex, @RequestParam("PageSize") int pageSize)`；前端 `style.ts` 第 88 行 `getAllListPage: (body, PageIndex = 1, PageSize = 10)` | 改为 `(body, PageSize = 10, PageIndex = 1)` 以与 DataStyle 一致，避免后续维护踩坑 |
| **P0-2** | `views/style/index.vue`、`views/symbol/index.vue` | **分页 API 从未被调用**——两个页面列表均走 `getAllList`（全量），`getAllListPage` 是死代码。后端 35/6 端点里这两个分页端点无前端入口。 | `grep getAllListPage` 在 `.vue` 中命中 0 次 | 二选一：①页面改走分页（数据量大时必要）；②从 api 模块删除以减噪 |
| **P0-3** | `views/data/ResourceDetail.vue` | **属性表记录级 CRUD 无入口**。已接入的只有 `updateAttrtable`（单条改）；`insertAttrtable`（新增要素）、`deleteAttrtable`（删要素）、`updateAttrtableList`（批量改）**三项均未接入任何 UI**。 | `grep` 三个方法名在全部 `.vue` 中命中 0 次 | 在属性表工具栏补「新增记录 / 删除记录 / 批量编辑」三个入口 |
| **P0-4** | `views/style/index.vue` → `dataStyleApi.remove(row.id, 'admin')` | 调用签名正确（后端 `delete(id, user)` 两参数），但 **user 硬编码 `'admin'`**，与 `request.ts` 预留的 Token 体系脱节。 | `style/index.vue:325` | user 应取自登录态 / store，而非字面量 |

> 说明：P0-1 严格说是「隐患」而非「当前必炸」——默认值恰好对齐。真正会炸的调用级错误在本次核对中**未发现**，说明前期契约对齐做得扎实。

## 五、修复优先级建议

**P0（功能缺口，建议本轮补）**
1. 属性表记录增删改入口（`insertAttrtable` / `deleteAttrtable` / `updateAttrtableList`）——数据维护核心闭环。
2. 资源编辑弹窗（`layerContent/Update`）——当前只能删不能改。
3. `style/symbol` 列表改走分页 API，或明确保持全量并删死代码。

**P1（整块能力缺失）**
4. 「地图管理」模块：map 14 端点 + mapRelation 编排端点，至少补齐 新建/编辑地图、关联图层勾选、改图例/投影框。
5. user 硬编码 `'admin'` 统一改为登录态取值。

**P2（体验增强）**
6. 目录树懒加载（`getLayerTreeByType`）、点选查询（`pageAttrInfoByPoint`）、TIF 导出（`OutputTifFileData`）。
7. 分类计数（`GetAllCountByDataType`）、状态筛选（`GetAllListStatus`）。
