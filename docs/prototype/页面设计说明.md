# 空间数据管理系统 · 页面设计说明

> 交付物：`sdms-prototype.html`（单文件高保真可交互原型）
> 参考原型：`https://qmliq7.axshare.com` →「因子库 · 矢量数据 / 栅格数据」
> 后端依据：`docs/接口文档.md`（`geodata-service`，端口 8982，20 个 Controller / 200 个端点）
> 说明：本文档中所有接口路径、参数名大小写、返回结构均逐端点核对自源码，非推测。

---

## 1. 原型还原与差异

### 1.1 从 Axure 原型提取到的结构

| 层级 | 内容 |
|:---|:---|
| 顶部主菜单 | 区域评价 ｜ 单体评价 |
| 左侧二级导航 | 因子库（矢量数据 / 栅格数据 / 文本数据）、空间数据（原始空间数据管理 / 历史灾害库 / 结果空间数据管理）、模型管理、权重计算 |
| 页面三栏 | 左：资源目录树；中：查询条 + 数据列表；右：地图预览 + 详情 |
| 工具栏 | 新增 / 编辑 / 删除 / 上传 / 查询 / 重置 |
| 查询字段 | 数据名称、上传时间、因子类别、空间参考系、分类、数据类型、创建时间、所有者、行政区划 |
| 列表字段 | 数据名称、空间参考系、数据类型、分类、创建时间、所有者（栅格页多「重分类时间」） |
| 特有交互 | 矢量↔栅格**互转**、栅格**重分类**（树分「原始数据 / 重分类数据」两组）、新增因子类别、地图内容展示 |

### 1.2 本设计在原型基础上的补全

1. **每个交互点标注后端接口**：顶栏「接口注释」开关开启后，所有可交互元素出现虚线框 + 编号角标（① ② ③…，按方法着色 GET 绿 / POST 蓝 / DELETE 红），编号与右上「本页接口」清单一一对应，悬浮显示入参/返回/注意事项。
2. **补充分页、导出、任务记录、操作日志**等原型未画但后端已具备的能力入口。
3. **补充地图子页签**：地图 / 属性表 / 元数据 / 样式，对应四组独立接口。
4. **补充异步任务进度弹窗**：图层工具与拓扑检查统一为「提交 → 返回 taskId → 轮询 → 成果入库」四段式。

### 3.6 矢量 ↔ 栅格互转（原型核心交互）

| 方向 | 方法 | 接口 | 参数 | origin |
|:---|:---:|:---|:---|:---:|
| 矢量 → 栅格 | POST | `/layerTool/shpToTif` | `shpToTifDto`{attributeName,x,y,height,width,type}；`type` 1 空间分辨率 / 2 网格大小 | 4 |
| 栅格 → 矢量 | POST | `/layerTool/tifToShp` | `tifToShpDto`{attributeName}；`uploadFileType=1` | 3 |
| 轮询进度 | GET | `/layerTool/getList` | `pageSize`、`pageIndex`、`origin`；按 `createDT` 倒序 | — |
| 成果入库 | GET | `/layerTool/storageLayer` | `id`(任务 ID)、`targetId`(目标目录 ID) | — |

统一请求体 `LayerToolDto`：`layerId / layerName / detailJson / createBy / taskId / taskType / 各专属 dto`；统一返回 `Result<String>`（taskId）。

## 4. 对接注意事项（来自接口文档 §21，前端必读）

| 类别 | 说明 |
|:---|:---|
| **裸返回端点** | `LayerContent` 的 `GetAllCount`(Integer)、`GetAllListByName`(ListResultOutput)、`GetPageListByName`(PagedResultOutput)、`GetAllListByMapID`(ListResultOutput)、`GetLayerAttrTabledDetail`(String)、`InsertImageLayer`(MapEntity)、`Delete`/`DeleteLayer`(boolean)、`GetLayerAttrTableByWhere`/`GetAttrtableByLayerId`、`InsertAttrtable`/`DeleteAttrtable`、`GetFieldByLayerId`、`ValidateCondition`；`LayerField` 的 `GetAllList`/`GetDetailByLayerID`；`DataType` 的 `GetAllListByDataType`/`GetDetailByName`；`DataTag` 的 `GetAllListByDataType`。**这些响应没有 `Result` 外壳，直接是数据体。** |
| **压缩返回** | `getLayerTree` / `getLayerTreeByType` 返回压缩字符串，需先解压 |
| **列表字段名** | `ListResultOutput` 字段是单数 `item`；`PagedResultOutput` 是 `totalCount` + `items`；空间查询是 `records/layerName/layerId/total` |
| **参数大小写混用** | `mapID` / `layerID` / `dataTypeID` / `PageSize` / `PageIndex` / `MapId` / `mapid` / `id` / `layerId`，须逐端点按文档书写，不可统一转换 |
| **表单 vs JSON** | `MapController.Insert/Update/GetAllListByName` 与 `LayerContentController.InsertImageLayer` **无 `@RequestBody`**，走 `application/x-www-form-urlencoded` |
| **GET 带 Body** | `/dataStyle/GetXmlContent` 为 GET + `@RequestBody`，部分网关会丢弃 Body |
| **异步任务** | 9 个图层工具 + 拓扑 `/check` + 三维 `/convert` 均为「返回 taskId → 轮询」，实时进度走 SignalR 推送至 .NET IM 服务 |
| **空壳端点** | `/systemUser/GetUserDataByUserCodeAsync` 返回 `null`，前端勿依赖 |

## 5. 原型使用方法

1. 浏览器直接打开 `docs/prototype/sdms-prototype.html`（单文件，无外部依赖）。
2. 左侧二级导航切换 8 个页面；顶栏可切「区域评价 / 单体评价」。
3. 点击数据卡片 → 右侧地图 / 属性表 / 元数据 / 样式 联动。
4. 卡片按钮：编辑、转栅格（栅格页为「转矢量」）、重分类、样式、更多▾（16 项操作）。
5. 顶栏「接口注释」开关 → 全页标注编号角标；点角标或「本页接口」查看接口清单。
6. 「新增 / 上传 / 互转 / 重分类」按钮会弹出真实形态的表单与异步任务进度弹窗。
