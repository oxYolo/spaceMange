# OGC 服务协议使用说明（WMS / WMTS / WFS / MVT / 3DTiles）

> 本文档说明空间数据管理平台发布的各类 OGC 服务的**协议原理、地址形态、完整请求参数、客户端接入方法（QGIS / ArcGIS / OpenLayers / Cesium / GDAL）与常见问题**。
> 所有地址形态均与后端 `ServerInterfaceServiceImpl` 实际生成逻辑一一对应，非通用模板。
>
> - 服务端：GeoServer（工作区 `sdms`，数据存储 `sdms_pg`，默认坐标串 `EPSG:4326`）
> - 发布入口：资源详情「服务与发布」页签 → `POST /serverInterface/publishService`
> - 地址查询：`GET /serverInterface/getServerInterface?dataId={图层id}&serverType={WMS|WMTS|WFS|MVT}`
> - 切片进度：`GET /serverInterface/tileProgress?dataId={图层id}`（GWC seed 任务，IDLE/RUNNING/DONE/FAILED）

---

## 1. 总体机制：先发布，后用服务

| 步骤 | 说明 |
|---|---|
| ① 数据入库 | 矢量（SHP/GeoJSON 等）或栅格（GeoTIFF）上传后写入 PostgreSQL/PostGIS，同时向 GeoServer 注册要素类型（工作区 `sdms`） |
| ② 发布 | `publishService` 将图层 `publishStatus` 置 1。**不传 publishType 时默认仅 WMS**（图层入库即已可用，不触发切片）；显式传 `WMTS` / `MVT` 时才向 GWC 提交切片任务 |
| ③ 切片（可选） | WMTS / MVT 需要 GWC 预切片，提交后异步执行，进度见 `tileProgress`；切片提交失败会自动回退发布状态（避免"假发布"） |
| ④ 取地址 | `getServerInterface(dataId, serverType)` 返回该类型服务的完整请求地址（含示例参数值） |
| ⑤ 用服务 | 平台内「服务预览」按类型挂载地图；也可复制地址到 QGIS / ArcGIS / 等客户端 |

数据类型与可用协议的对应关系：

| 数据类型 | WMS | WMTS | WFS | MVT | 3DTiles |
|---|---|---|---|---|---|
| 矢量（点/线/面） | ✅ | ✅（需切片） | ✅ | ✅（需切片） | — |
| 栅格（DOM/DEM） | ✅ | ✅（需切片） | — | — | — |
| 三维（OSGB/LAS/OBJ/FBX/IFC/3DTiles） | — | — | — | — | ✅ |

## 2. WMS —— 动态渲染地图服务

### 2.1 协议原理
服务端根据请求参数（范围、尺寸、图层、样式）**实时渲染**并返回一整幅地图图片。无需预切片、数据实时性最好；每次请求都有渲染开销。

### 2.2 地址形态（后端实际生成）

```
http://{geoServerIP}:{geoServerPort}/geoserver/{workspace}/wms
  ?service=WMS
  &version=1.1.0
  &request=GetMap
  &layers={workspace}:{layerAttrTable}
  &bbox={minX},{minY},{maxX},{maxY}      # 优先取图层自身四至，其次取要素类型 latLonBoundingBox
  &srs=EPSG:4326                          # 默认 EPSG:4326
  &styles=                                # 空 = 默认样式
  &width=768
  &height=670
  &format=image/png
  [&transparent=true]                     # 叠加显示必填
  [&bgcolor=FFFFFF]
  [&exceptions=application/vnd.ogc.se_xml]
  [&time=yyyy-MM-ddThh:mm:ss.SSSZ]
  [&sld={URL} | sld_body={SLD XML}]       # 临时替换样式
```

> `layers` 使用 `工作区:属性表名` 全限定名，例如 `sdms:cb_road`。

### 2.3 完整请求参数表（与后端 `getWMSInfo` 一致）

| 参数 | 必填 | 取值 / 示例 | 说明 |
|---|---|---|---|
| service | 是 | `WMS` | 服务类型 |
| version | 是 | `1.0.0`~`2.0.0`，默认 `1.1.0` | 版本 |
| request | 是 | `GetMap` / `GetCapabilities` / `GetFeatureInfo` | 请求类型 |
| layers | 是 | `sdms:cb_road` | 图层名（工作区:要素类型） |
| bbox | 是 | `113.8,29.5,114.1,29.9` | 边界范围（minX,minY,maxX,maxY） |
| srs | 是 | `EPSG:4326` | 坐标参考系 |
| styles | 是 | 空 = 默认样式 | 图层样式（SLD 名） |
| width | 是 | 正整数，示例 768 | 图片宽（px） |
| height | 是 | 正整数，示例 670 | 图片高（px） |
| format | 是 | `image/png`（另支持 jpeg、tiff、geotiff、svg、pdf、kml…） | 返回格式 |
| transparent | 否 | `true/false`（默认 false） | 背景透明（叠加底图时用 true） |
| bgcolor | 否 | `RRGGBB`（默认 FFFFFF） | 背景色 |
| exceptions | 否 | 默认 `application/vnd.ogc.se_xml` | 异常返回格式 |
| time | 否 | ISO8601 | 时间维度（多维数据） |
| sld | 否 | URL | 远程样式文件地址 |
| sld_body | 否 | SLD XML 文本 | 内联样式（覆盖服务端样式） |

### 2.4 常用请求示例

**浏览器直开（快速验证图层是否发布成功）：**
```
http://localhost:8081/geoserver/sdms/wms?service=WMS&version=1.1.0&request=GetMap
&layers=sdms:cb_road&bbox=113.8,29.5,114.1,29.9&srs=EPSG:4326&styles=&width=768&height=670&format=image/png
```
返回 PNG 即成功；返回 ServiceException 说明图层名/范围/权限有问题。

**查看服务能力文档（有哪些图层、支持哪些格式与 SRS）：**
```
http://localhost:8081/geoserver/sdms/wms?service=WMS&version=1.1.0&request=GetCapabilities
```

**点选取值（属性查询）：**
```
…/wms?service=WMS&version=1.1.0&request=GetFeatureInfo&layers=sdms:cb_road
&query_layers=sdms:cb_road&bbox=…&srs=EPSG:4326&width=768&height=670
&x=384&y=335&info_format=application/json
```

### 2.5 客户端接入

- **QGIS：浏览器面板 → WMS/WMTS → 新建连接**，填 `http://{ip}:{port}/geoserver/sdms/wms`，连接后勾选图层。
- **ArcGIS：目录 → GIS Server → 添加 WMS Server**，同上。
- **OpenLayers：** `new TileLayer({ source: new TileWMS({ url, params: { LAYERS: 'sdms:cb_road', TILED: true, FORMAT: 'image/png', TRANSPARENT: true } }) })`（平台「服务预览」即此实现，地址中的 bbox 会用来做视图适配）。
- **命令行取图：** `curl -o out.png "http://localhost:8081/geoserver/sdms/wms?service=WMS&…&format=image/png"`。

### 2.6 常见问题
| 现象 | 原因 / 处理 |
|---|---|
| 图片全白/全透明 | bbox 与图层实际范围不符（复制地址时请用后端返回的 bbox）；transparent=true 且图层确实无数据 |
| 中文标注乱码 | SLD 内字体不含中文或 GeoServer 未配置中文字体；在「样式库」改用系统中文字体 |
| 样式不生效 | styles 传了样式名但 GeoServer 无该样式；先在「样式库 → 推送 GeoServer」 |
| 大图很慢 | WMS 实时渲染，改用 WMTS 切片或缩小 width/height |

## 3. WMTS —— 预切片瓦片服务

### 3.1 协议原理
GeoServer GWC（GeoWebCache）把图层按金字塔层级预切成 256×256 瓦片，客户端按 `层级/列/行` 直接取瓦片。速度快、可缓存，适合栅格与大范围浏览；**必须先发布切片（publishType 传 WMTS）并等切片任务完成**。

### 3.2 地址形态（GWC WMTS 端点）

```
http://{geoServerIP}:{geoServerPort}/geoserver/gwc/service/wmts
  ?SERVICE=WMTS
  &VERSION=1.1.0
  &REQUEST=GetTile
  &LAYER={workspace}:{layerAttrTable}
  &TILEMATRIXSET=EPSG:4326            # 另有 EPSG:900913
  &TILEMATRIX=EPSG:4326:{z}           # 示例值为 z=7
  &TILECOL={x}
  &TILEROW={y}
  &format=image/png                   # 支持 image/png、image/jpeg
  [&style=]
```

> **注意**：后端返回的 `TILECOL/TILEROW/TILEMATRIX` 只是按图层中心计算的一个**样例瓦片**，用于演示参数拼法；客户端接入必须使用能力文档或按网格自行计算行列号（见 3.4）。EPSG:4326 网格原点在左上，TILEROW 自上而下递增。

### 3.3 能力文档

```
http://{ip}:{port}/geoserver/gwc/service/wmts?SERVICE=WMTS&VERSION=1.1.0&REQUEST=GetCapabilities
```
其中 `TileMatrixSet` 定义了每层的分辨率与瓦片原点，客户端据此计算行列号。

### 3.4 客户端接入

- **QGIS：浏览器面板 → WMS/WMTS → 新建连接**，填 `http://{ip}:{port}/geoserver/gwc/service/wmts?SERVICE=WMTS&VERSION=1.1.0`，QGIS 自动读能力文档加载。
- **OpenLayers：** 用 `WMTSCapabilities` 读能力文档 + `optionsFromCapabilities` 构建 `WMTS` source（平台「服务预览」的 WMTS 分支即此实现，跨域未开放时会给出明确提示）。
- **手拼瓦片 URL（调试用）：**
  ```
  http://localhost:8081/geoserver/gwc/service/wmts?SERVICE=WMTS&VERSION=1.1.0&REQUEST=GetTile
  &LAYER=sdms:dom_2024&TILEMATRIXSET=EPSG:4326&TILEMATRIX=EPSG:4326:10&TILECOL=843&TILEROW=392&format=image/png
  ```

### 3.5 切片进度与常见问题
- 切片未完成时平台预览会提示「切片中」，进度见 `GET /serverInterface/tileProgress?dataId=…`（RUNNING/DONE/FAILED）。
- 瓦片 404：该层级/行列没有数据，或切片方案（TileMatrixSet）与客户端不一致——优先用能力文档接入。
- 数据更新后瓦片不刷新：需要重新提交切片（GWC 截断 + seed）。

## 4. WFS —— 矢量要素服务

### 4.1 协议原理
直接返回要素的**几何 + 属性**（GML/GeoJSON），支持按条件过滤。用于要素下载、属性核查、第三方编辑；**不做底图渲染**（平台预览中对 WFS 仅提供地址）。

### 4.2 地址形态

```
http://{geoServerIP}:{geoServerPort}/geoserver/{workspace}/wfs
  ?service=WFS
  &version=1.1.0
  &request=GetFeature
  &typeName={workspace}:{layerAttrTable}
  [&outputFormat=application/json]        # GeoJSON（默认 GML 3.1.1）
  [&featureID={表名}.{gid}]               # 按主键取单要素
  [&CQL_FILTER={属性条件}]                # 如 name='主干道' AND length>500
  [&srsName=EPSG:4326]
  [&maxFeatures=1000]
```

### 4.3 常用请求示例

**取全部要素（GeoJSON）：**
```
http://localhost:8081/geoserver/sdms/wfs?service=WFS&version=1.1.0&request=GetFeature
&typeName=sdms:cb_road&outputFormat=application/json&maxFeatures=1000
```

**属性过滤：**
```
…/wfs?service=WFS&version=1.1.0&request=GetFeature&typeName=sdms:cb_road
&outputFormat=application/json&CQL_FILTER=length>500
```

**查看字段结构：**
```
…/wfs?service=WFS&version=1.1.0&request=DescribeFeatureType&typeName=sdms:cb_road
```

### 4.4 客户端接入
- **QGIS：** WFS 连接 `http://{ip}:{port}/geoserver/sdms/wfs`，或直接拖 DescribeFeatureType 结果。
- **GDAL/ogr2ogr 转本地文件：** `ogr2ogr -f GeoJSON out.json "WFS:http://localhost:8081/geoserver/sdms/wfs" sdms:cb_road`
- **平台内替代能力：** 资源详情「数据与要素」页签的属性表、条件筛选、框选查询、导出 SHP，底层即 WFS/空间 SQL 的等价实现，无需直接拼 WFS 地址。

## 5. MVT —— Mapbox 矢量瓦片

### 5.1 协议原理
瓦片内保留几何与属性（`application/vnd.mapbox-vector-tile`），客户端可**动态换肤、无级缩放不失真、体积小**，适合大数据量矢量图层的 Web 高性能展示。本平台经 **GeoServer GWC 的 WMTS 端点**分发（format 取矢量瓦片），发布时 `publishType` 传 `MVT` 触发切片。

### 5.2 地址形态（后端 getMVTInfo 生成）

```
http://{geoServerIP}:{geoServerPort}/geoserver/gwc/service/wmts
  ?SERVICE=WMTS
  &VERSION=1.1.0
  &REQUEST=GetTile
  &LAYER={workspace}:{layerAttrTable}
  &TILEMATRIXSET=EPSG:4326
  &TILEMATRIX=EPSG:4326:{z}
  &TILECOL={x}
  &TILEROW={y}
  &format=application/vnd.mapbox-vector-tile
```

### 5.3 前端接入要点（平台「服务预览」实现）
后端样例地址中的行列号不可直接使用，`Map2D.addMvt()` 的做法是：
1. 解析样例地址得到基地址与 `LAYER`；
2. 用 `ol/source/VectorTile` + `ol/format/MVT`，`projection: 'EPSG:4326'`，瓦片网格 `createXYZ({ extent: [-180,-90,180,90] })`（左上原点，TILEROW 自上而下，与 GeoServer EPSG:4326 网格一致）；
3. `tileUrlFunction` 按 `[z,x,y]` 重组上面的 URL。

MapLibre GL / Mapbox GL 接入示例（style.json 的 vector source）：
```json
{
  "type": "vector",
  "tiles": ["http://localhost:8081/geoserver/gwc/service/wmts?SERVICE=WMTS&VERSION=1.1.0&REQUEST=GetTile&LAYER=sdms:cb_road&TILEMATRIXSET=EPSG:4326&TILEMATRIX=EPSG:4326:{z}&TILECOL={x}&TILEROW={y}&format=application/vnd.mapbox-vector-tile"],
  "minZoom": 0, "maxZoom": 21
}
```
QGIS 亦可直接添加该 WMTS 地址并选择矢量瓦片格式。

### 5.4 常见问题
| 现象 | 原因 / 处理 |
|---|---|
| 瓦片空白 | GeoServer 未启用 `application/vnd.mapbox-vector-tile` 输出格式，或该层级未切片/不允许按需切片 |
| 要素偏移 | 行列号原点约定不一致（GeoServer EPSG:4326 左上原点，勿用 XYZ 的 3857 行列） |
| 属性丢失 | MVT 只保留瓦片内属性；需要全量属性走 WFS 或平台属性表 |

## 6. 3DTiles —— 三维服务

### 6.1 协议原理
Cesium 生态的三维瓦片流式加载规范（3D Tiles 1.0），按 LOD 调度，用于 OSGB 倾斜摄影、LAS/LAZ 点云、OBJ/FBX 单体、IFC/BIM 的 Web 发布。由平台三维转换链路产出（状态机：上传→转换→发布），**状态「已发布」（4）后** `GET /model3d/{id}/publish-url` 返回 tileset.json 地址。

### 6.2 接入
- 平台内：「数据管理 → 预览」自动用 Cesium 加载（`Map3D.vue`）。
- 外部 Cesium：
  ```js
  const tileset = viewer.scene.primitives.add(new Cesium.Cesium3DTileset({ url: 'http://{host}/…/tileset.json' }))
  viewer.zoomTo(tileset)
  ```

## 7. 样式与协议的关系

| 环节 | 说明 |
|---|---|
| 样式存储 | 「样式库」管理 SLD（单一符号 / 分级设色 / 唯一值 / 栅格分级 / 三波段），支持按图层绑定（`styleDefaultLayer` ↔ `layerDefaultStyle`） |
| 推送到 GeoServer | 样式「推送 GeoServer」后，WMS `styles` 参数传样式名即可生效；`sld/sld_body` 可临时覆盖 |
| 地图换样式 | `POST /mapreleation/ChangeStyle?mapid=&layerStr=&styleStr=` 批量切换地图内图层样式 |
| 切片服务注意 | WMTS/MVT 切片**缓存的是一段时间内的渲染结果**，换样式后需重新切片（刷新 GWC 缓存）才能看到新样式 |

## 9. 平台内使用路径

1. **数据管理页**：已发布行显示可用格式标签（WMS/WFS/WMTS/MVT），可复制地址、全屏预览。
2. **服务预览**：侧栏列出该图层**全部**可用服务（含协议说明与地址），**点击即切换**地图加载（WMS 渲染 + 自动适配图层四至；WMTS 能力文档挂载；MVT 矢量瓦片；WFS 仅地址）。
3. **资源详情 → 服务与发布**：发布服务、查询全部服务地址（含协议说明）、逐个复制；所属地图列表。
4. **属性查询**：资源详情「数据与要素」页签提供属性表、条件筛选、框选/圈选/点选/缓冲查询与导出，等价于 WFS + 空间 SQL 的能力。

## 10. 排查清单（服务不通时按序检查）

1. 图层 `publishStatus` 是否为 1（未发布先「发布为服务」）；
2. GeoServer 中是否存在 `sdms:{layerAttrTable}` 要素类型（能力文档中查）；
3. 地址中的工作区/图层名大小写、`layers` 是否为 `工作区:表名` 全限定名；
4. bbox/srs 是否与数据一致（WMS 白图优先查这两项）；
5. WMTS/MVT：切片任务是否 DONE（`tileProgress`），GWC 是否允许按需切片、是否启用对应 format；
6. 跨域：GeoServer 未开放 CORS 时，平台外的前端直连会被浏览器拦截（平台内走同源代理不受影响）；
7. 权限：GeoServer 账号（默认 `geoserver/geoserver`）对工作区是否有读写权限。
